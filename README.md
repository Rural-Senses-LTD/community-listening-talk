# AI Will Make Community Listening Easier. Will We Actually Listen?

A 3-minute talk by Yau Levy, co-founder of [Rural Senses](https://ruralsenses.com), based on his LinkedIn article of 12 October 2026.

**Live deck:** https://rural-senses-ltd.github.io/community-listening-talk/

## Presenting

- Arrow keys or Space: next and previous slide
- N: speaker notes with each slide's target time and a running clock (T resets the clock)
- F: full screen

## Editing

The deck is one self-contained file, `index.html`, built from source:

```
python build.py
```

- `src/slides.template.html`: slides, styles and scripts
- `src/viewport-base.css`: viewport base styles from the skills-slides skill
- `images/`: photos and logos, inlined into `index.html` at build time
